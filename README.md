Web Kalkulator BMI ini dibuat untuk memudahkan pengguna dalam menghitung Indeks Massa Tubuh(BMI). 
Sistem akan langsung memproses berat dan tinggi badan untuk mengklasifikasikan pengguna ke dalam status kategori kesehatan, mulai dari 'Kurus' hingga 'Obesitas'.
